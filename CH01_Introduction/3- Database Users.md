- Who the users of a database are and the process of creating a database system?
- **Step-1:** Analysis and requirement gathering
	- Start to discuss with the client , why he needs for this system, and what is the nature of using the database, and if he changing the data regularly or he is adding a new data every day, and who are the users will deal with the database, and how many users we have, and what us the size and format of the data, and what is the growth rate of the data.
	  Trying to collect all this data and try to know more about his infrastructure, 
	  and one of the important things also is his budget.
	- By **System Analysts** 

- **Step-2:** Database Design
	- Check what is the format of the database design, and creates the database design and converts it into tables and objects, (Conceptual Schema).
	- By **Database Designer**

- **Step-3:** Implementation
	- Installs the DBMS, sets up the system, creates database objects (schema), loads initial data, manages user privileges, and maintain database performance.
	- By **(DBA) Database Administrator**

- **Step-4:** Application development
	- develops the user interface and applications for end users, who interact with the system through these interfaces to perform their tasks. Each role contributes to building a functional, secure, and efficient database system.
	- By **Application programmer**
