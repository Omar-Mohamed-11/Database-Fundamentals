# Database Fundamentals

Structured personal study notes for the **Database Fundamentals** course. The repository follows the course chapter by chapter, from core database concepts and entity-relationship modeling through SQL and normalization.

## Overview

These notes were created while studying Database Fundamentals and are intended for learning and reference. They include concept explanations, SQL syntax and examples, and supporting diagrams where applicable.

## Course Structure

| Chapter | Topic | Description |
| --- | --- | --- |
| [CH01](./CH01_Introduction/) | Introduction | Database concepts, systems, users, DBMS architecture, mappings, and centralized or distributed environments. |
| [CH02](./CH02_Entity_Relationship_Diagram/) | Entity-Relationship Diagram | Entity-relationship modeling, entities and attributes, and relationship degree, cardinality, and participation. |
| [CH03](./CH03_ERD_Mapping_to_Tables/) | ERD Mapping to Tables | Rules for mapping strong and weak entities and relationship types to relational tables. |
| [CH04](./CH04_Structured_Query_Language%28SQL%29/) | Structured Query Language (SQL) | Database schema and constraints, data definition language, and data control language. |
| [CH05](./CH05_Data_Manipulation_Language_%28DML%29/) | Data Manipulation Language (DML) | SQL data manipulation, queries, joins, subqueries, aggregation, and result filtering. |
| [CH06](./CH06_SQL_other_DB_objects/) | Other SQL Database Objects | Views and indexes. |
| [CH07](./CH07_Normalization/) | Normalization | Functional dependency and the first, second, and third normal forms. |
